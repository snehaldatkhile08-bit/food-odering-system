# Foodie — Online Food Ordering System

A simple front-end demo project made with HTML, CSS, and JavaScript.

## Features
- Responsive food menu
- Category filters and live search
- Add items to cart
- Increase/decrease item quantities
- Automatic total calculation in INR
- Checkout form with basic validation
- Demo order confirmation (no real payment or delivery request)

## How to run
1. Extract `online_food_ordering_system.zip`.
2. Open the `online_food_ordering_system` folder.
3. Double-click `index.html` or open it in a browser.

No installation or server is required. An internet connection is only needed for the optional Google Fonts import.

## Project structure
- `index.html` — page structure
- `style.css` — layout and responsive styling
- `script.js` — menu, cart, and checkout functionality

## Note
This is a learning/demo project. It does not include a backend, database, user authentication, order persistence, or real payment processing.
